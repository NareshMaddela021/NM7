# Full-width layout: before and after

Every page except the home page now uses the whole screen, with 24 px side padding (16 px on phones). Screenshots at **1920 px**, **1440 px** and **390 px** (phone), taken by `frontend/e2e-live/zz-shots-wide.spec.mjs` in the e2e workflow: "before" is `main`, "after" is this branch. Made-up demo data; some lists are empty on the test server.
