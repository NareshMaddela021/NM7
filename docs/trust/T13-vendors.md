# Vetting Trust T13: vendors

**Nothing to sign up for, no cost, and no new Render env vars.**

The time-to-hire dashboard is counting in Nm7's own database: the times already stored when a company invites someone,
moves an applicant, books an interview, sends an offer (and T5 / T11 messages), plus one small new collection
(`trust_hire_events`) that keeps the first time a job reached each step. No AI calls, no outside service, no WhatsApp or
email is sent by it.
