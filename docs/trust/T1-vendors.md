# Vetting Trust T1 (DPDP pack): vendors

**Nothing to sign up for.** T1 uses only what nm7.si already has: MongoDB, the existing email provider (Resend /
ZeptoMail) for the parent's consent link and the inactivity warning, and the existing automation pass.

No new Render environment variables.

Later, optional:
- **SMS for the parent's link** (instead of email only): an SMS provider with DLT registration (e.g. MSG91 or
  Twilio India). Roughly ₹0.15–0.25 per SMS plus a one-time DLT entity/template registration (≈ ₹5,900 on some
  operators). Not built yet; the parent link goes by email.
